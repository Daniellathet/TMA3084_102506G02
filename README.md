# MA3084 SELAB - Lab 1: Pizza Order Calculator

## Description

A Dart program that calculates pizza order payments using a switch statement and a while loop.

## Pizza Prices

* Small: $5 USD
* Medium: $7 USD
* Large: $10 USD

## Setup Instructions

1. Install the Dart SDK.
2. Open this folder in Visual Studio Code.
3. Open the integrated terminal.

## How to Run

Run the following command in the terminal:


dart run pizza_order.dart
